File Organization

MPS
*Files for controlling Model Position System, used to adjust angle of attack*
% The MPS is controlled by tcp/ip commands from another computer on the AFAM
% tunnel network

VFD
*Files for controlling Variable Frequency Drive, used to control wind tunnel
fan motor*
% The VFD is controlled by tcp/ip commands from another computer on the AFAM
% tunnel network

DAQ
*Files for collecting data from the National Instruments Data Acquisiton
Device (NI DAQ)*
% Contains a benchtop test script

Wind Tunnel Test
*Files for running a full force experiment with Calimero mounted in the
tunnel*

Kinematics
*Files plotting Calimero wingbeat motion profiles from CAD and theory*

PIV
*Files for processing PIV data collected for the Calimero experiment*

General
*Functions that are generally useful*

Galil Scripts
*Galil Digital Motion Controller (dmc) files called either in a benchtop or
wind tunnel test*

data analysis
*Files for processing and plotting force, voltage, and current data collected
from experiments with Calimero in the wind tunnel*
